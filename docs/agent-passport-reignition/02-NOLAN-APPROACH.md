# The Nolan Approach

> **OPERATING REFERENCE:** Execution starts from [01 — Agent Passport Execution Plan](./01-EXECUTION-PLAN.md). This file governs how that plan is read, bounded, and revised.

This is Agent Passport's local planning method. It is not a claim about a formal external methodology.

> Know the ending. Get to the location. Let the location rewrite the scene.

## Operating rules

1. Hold the outcome firmly; hold the route loosely.
2. Plan deeply enough to coordinate the next move, not to predict the whole campaign.
3. Separate known facts from assumptions, open questions, and dependencies.
4. Define the next **location** as observable evidence, not elapsed time or completed activity.
5. At that location, inspect reality before expanding the plan.
6. Record what changed, rewrite the next move, and remove work that no longer earns its place.
7. Do not use flexibility as an excuse for vague execution. Every active move still needs an owner, bounded scope, evidence, and a stop condition.

## Stage discipline

At the start of every stage:

- Read this file and the active plan.
- Recheck live product, repository, customer, and distribution facts that the stage depends on.
- Confirm the stage's next location and what is deliberately not being planned yet.

At the end of every stage:

- Put findings in the plan's **Review and Replan** section.
- Update Known Ground, assumptions, deferred work, and the next move.
- Report the evidence and plan changes to the user before starting the next stage.

The active plan remains the control document. Durable product truth belongs in the product's permanent documentation after it is proven.
